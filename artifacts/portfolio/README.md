# Portfolio screenshots

These images are generated by the real Playwright browser flow in
`frontend/e2e/investigation.spec.ts`. The flow talks to the real FastAPI service and PostgreSQL
queue, lease, report-publication, review, and resume contracts. It uses a deterministic publisher
that is visibly labeled in the report and evidence limitations. It makes zero model calls and is
not presented as an AI-quality result.

Generate the screenshots after local configuration with:

```bash
make portfolio-screenshots
make portfolio-verify
```

Sanitization properties:

- no bearer token, database password, DSN, model key, or personal identity is visible;
- the displayed owner is the fixed test principal `phase7-e2e-owner`;
- the provenance URI uses the fixed `fixture://phase7/playwright/metric` namespace;
- investigation UUIDs and request prefixes are ephemeral fixture identifiers;
- every diagnostic statement shown is served by the deterministic fixture and labeled as such.

Files:

- `01-report-and-review.png` — API-backed report, event, dependency view, and review boundary.
- `02-evidence-drilldown.png` — cited metric record, provenance, limitation, and chart.
- `03-completed-and-follow-up.png` — completed lifecycle and immutable versioned continuation.
